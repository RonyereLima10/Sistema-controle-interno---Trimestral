Backups dos trabalhos

Crie quantos backups forem necessários. Cada backup é armazenado separadamente no navegador, com data, hora, exercício, trimestre e identificação do relatório. O backup preserva os campos preenchidos do sistema, inclusive os campos dinâmicos da Cota-parte.

Os backups locais ficam vinculados a este navegador e computador. Para segurança adicional, exporte os backups em arquivo JSON e mantenha uma cópia externa.
